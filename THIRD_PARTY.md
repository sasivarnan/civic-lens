# Third-party components

- shadcn/ui: MIT. Preset `b27GcrRo` generated the Base UI Rhea components.
- Base UI: MIT. Component source and dependency notices remain with the packages.
- Inter: SIL Open Font License. The font package contains its license.
- Lucide: ISC. Icons come from `lucide-react`.
- Leaflet: BSD-2-Clause. OpenStreetMap tiles and data require separate attribution.
- MediaPipe Tasks Vision and the BlazeFace short-range model: see the upstream Apache-2.0 project and model distribution terms. Setup downloads the model from Google's published MediaPipe model location.
- Gemma and EmbeddingGemma: separate model licenses and provider terms apply. Models are not included in this source repository.
- Garage, PostgreSQL, PostGIS, pgvector, and Mailpit: external development services retain their own licenses. Garage is a separate S3-compatible service; it is not copied into the application image.

The application MIT license does not replace third-party package, service, map-data, or model licenses. Package license files remain in the dependency distributions.
